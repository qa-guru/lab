Как агент это видит

В IDE rule включается сам. Skill читают фразой «прочитай SKILL.md». RAG — 2–4 пути, которые назвал skill. ADR — цитата «почему так».

Наращивание: skill → + rule → + RAG (занятие 3) → + ADR (занятие 4). Листы 10–13 — тот же сюжет с выключенными слоями. Живой login: 30–35 (Context — сцена, не слой). main — логин / items, без note. develop — заметка влита, ярусы takeaway 6/6.

Пак: docs/agent-skills/PACK.md Rule 01: один task test + tags · @Tag("smoke") — prod slice (ADR 005) занятия 2–4
