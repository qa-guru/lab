     -Dtest=LoginTests#<method>

# ADR 009: UI-текст e2e, 401 JSON — api
Статус: принято

Контекст: неверный пароль — форма и JSON.
В чате хочется закрыть JSON кликом.

Решение:
- текст на форме →
  LoginTests#shouldShowErrorWhenPasswordIsWrong
- 401 JSON → уже
  AuthApiTests#loginWithInvalidPassword
- браузерный тест под HTTP-статус не пишем

Последствия:
- не $("pre") «401»
- селекторы и текст ошибки — RAG, не ADR

как попадает: skill ссылается, сам не копирует

class LoginPage {

  loginInput    = $("[data-testid='login-input']");
  passwordInput = $("[data-testid='password-input']");
  submitButton  = $("[data-testid='submit-button']");

  @Step("Open login page")
  LoginPage openPage() {
    open("/login");
    return this;
  }

  @Step("Fill and submit form")
  HomePage fillAndSubmitForm(String username, String password) {
    typeUsername(username).typePassword(password).submit();
    return new HomePage();
  }

  @Step("Type username: {username}")
  LoginPage typeUsername(String username) {
    loginInput.setValue(username);
    return this;
  }

  @Step("Type password")
  LoginPage typePassword(String password) {
    passwordInput.setValue(password);
    return this;
  }
}
